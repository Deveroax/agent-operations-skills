# Compact inventory template

Covered by the [MIT License](../../../LICENSE); see [attribution](../../../ATTRIBUTION.md).

Keep one row per independently extractable component, with private evidence locators retained only in the private report. Avoid scores that imply unsupported precision.

| Component / source locator | Provenance class + evidence | Public value + audience | Verification receipt / not run | Privacy work | Rights / notices | Readiness + next action |
|---|---|---|---|---|---|---|
| Name; exact consulted files | Local authorship evidenced / upstream / adaptation / unresolved; basis | Narrow reuse thesis | Exact run and result, or unverified | Categories, never matched values | Declared license versus confirmed authority; missing permission | Extract / sanitize / contribute / exclude; required approval |

Report header: permitted roots; exclusions; cutoff; discovery method; unread sources; intended extraction scope. Append a component-level release list and independent exclusions. If useful, also serialize these same fields to JSON; do not include private payloads or invented metrics.

“Local authorship evidenced” is not inferred from a local path. Keep the creation record or explicit responsible-party confirmation distinct from license declarations. For adaptations, retain both the upstream basis and the local changes. Readiness is conditional on actual evidence and approval, not value alone.
